First preview release.

## What's in it

- **The feed format, v1** ([SPEC.md](https://github.com/Larmstrong1127/wristfeed/blob/main/SPEC.md)),
  with four layouts: stats, progress, message and dashboard.
- **The Python publisher** (`publisher/`): `validate`, `build`, `publish` to a GitHub gist, and
  `preview`, which renders a feed as an SVG of the tile.
- **The Wear OS app** (the APK below): one tile, a list of up to 5 feeds, a refresh every 30
  minutes, and the last good copy kept and dimmed when it gets old.
- **A shared conformance corpus of 60 cases**, run by both the Python and Kotlin test suites.

## Checked on a real watch (Galaxy Watch 8, Wear OS on Android 16)

- All four tile layouts.
- The stale state: dimmed, with an "Old data" footer.
- Adding and deleting feeds.
- The "On tile" choice.
- Refresh.

**Not yet checked on a device:** the three watch-face complication types. They are built and unit
tested, but not seen on a watch.

## Install

The APK is a **debug-signed preview build** (not from the Play Store). Turn on Developer options and
Wireless debugging on the watch, pair it with `adb pair`, then run:

```bash
adb install wristfeed-v0.1.0-debug.apk
```

Then open WristFeed on the watch, tap **Add feed** and enter an https URL (a raw secret-gist URL
works). Feeds must never contain secrets.
