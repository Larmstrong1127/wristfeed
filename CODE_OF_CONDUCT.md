# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, accept constructive criticism, and focus on what is best for the community. Harassment, insults and personal attacks are not tolerated.

Report unacceptable behavior to the maintainer through the contact link at https://larmstrong1127.github.io/. Reports are handled privately. Maintainers may remove comments, commits or contributors that break this code, following the Covenant's enforcement guidelines.
